# My agent: Smart Pantry Recipe Concierge

One-liner: A conversational agent that helps home cooks find recipes and manage meals with a catalog of pantry ingredients and dishes.

Tool coverage:
- Memory: Remembers dietary preferences, allergies, and cooking skill level across sessions.
- Tools: Looks up recipes by ingredients, computes nutrition info, generates shopping lists.
- Catalog/UI: Recipe collection and pantry item inventory cards.
- Image gen: Generates appetizing dish presentation photos.
- Sandbox: Computes nutritional macros and recipe scaling.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for nutrition calculations
